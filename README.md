### vim 快速注释和取消注释

```javascript
#注释方法一
5,11s/^/#/g  按下enter

大D 删除引号后面所有 ，大A插入模式

#取消注释方法一
5,11s/^#//g   按下enter

0 返回当前行的行首
dG 删除光标后所有的行
D  删除当前行光标后面的所有字.
yyp 复制当前行下面
yyP 复制当前行上面
vydp 复制字体
u 还原上次变更
Fn+Pgup向上翻页
fn+PgDn向下翻页
shift+$ 快速到这行的行尾
A  快速到这行的行尾，进入插入模式
:wq 保存退出

匹配增加，有点复杂，单独写到下面
将光标移动到修改区域的起始字元。
按下 Ctrl + v 进入可视块模式（屏幕左下角会显示 -- VISUAL BLOCK --）。
输入 9j，此时光标会向下选中 9 行的同一个字元位置。
按下大写的 Shift + i（即 I），进入插入模式（此时光标会回到第一行）。
输入你想要插入的内容（例如 test）。
关键步骤：按下 Esc 键两次

多行同时删除/替换内容
将光标移动到需要删除或替换的字元上。
按下 Ctrl + v 进入可视块模式。
输入 9j 选中 9 行。如果还要向右选中多个字元，可以用 l 键或左右方向键调整宽度。
如果纯删除：直接按下 d 键，选中的块就会被整体删除。
```
