### vim 快速注释和取消注释

```javascript
#注释方法一
5,11s/^/#/g  按下enter



#取消注释方法一
5,11s/^#//g   按下enter

#批量替换
:%s/10.10.10.10/10.10.10.11/g

0 返回当前行的行首
b 移动到当前单词的第一个
gg 移动到文件的行首
e 移动到当前单词的后面，比如master光标在m上面，按e会切换到r单词上
dG 删除光标后所有的行
C  删除当前行光标后面的所有字.
yy + 10p 当前行复制10行
yyp 复制当前行下面
yyP 复制当前行上面
vydp 复制字体
u 还原上次变更
Fn+Pgup向上翻页
fn+PgDn向下翻页
shift+$ 快速到这行的行尾
A  快速到这行的行尾，进入插入模式
dB 删除光标到行首的内容
:wq 保存退出


匹配增加，有点复杂，单独写到下面
将光标移动到修改区域的起始字元。
按下 Ctrl + v 进入可视块模式（屏幕左下角会显示 -- VISUAL BLOCK --）。
输入 9j，此时光标会向下选中 9 行的同一个字元位置。
按下大写的 Shift + i（即 I），进入插入模式（此时光标会回到第一行）。
输入你想要插入的内容（例如 test）。
关键步骤：按下 Esc 键两次

多行同时删除/替换内容
将光标移动到需要删除或替换的字元上。
按下 Ctrl + v 进入可视块模式。
输入 9j 选中 9 行。如果还要向右选中多个字元，可以用 l 键或左右方向键调整宽度。
如果纯删除：直接按下 d 键，选中的块就会被整体删除。

#命令行快捷键,不是vim
Ctrl + K：删除从光标处到行尾的所有字符。
Ctrl + U：删除从光标处到行首的所有字符。
Ctrl + W：向左删除一个单词
Alt  + D  向左删除一个单词
Ctrl + Y: 还原
Ctrl + E: 到最后
Ctrl + A: 到前面
Alt  + b: 按单词往前跳
```
